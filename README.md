# Portfólio - Andressa Alves Simão

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript para apresentar projetos, habilidades e contato profissional.

## Sobre o projeto

Este projeto é uma página estática que exibe informações sobre a desenvolvedora Andressa Alves Simão, incluindo:

- Introdução pessoal e apresentação
- Seção de habilidades técnicas
- Projetos com links para repositórios do GitHub
- Resumo de formação e experiência
- Serviços oferecidos
- Formulário de contato
- Modal interativo para detalhes dos projetos

## Tecnologias usadas

- HTML
- CSS
- JavaScript

## Recursos principais

- Layout responsivo e moderno
- Navegação âncora com seções claras
- Modal para visualização de detalhes dos projetos
- Elemento de retorno ao topo
- Campos de contato com `mailto:` para enviar mensagem diretamente por e-mail
- Design com foco em usabilidade e acessibilidade

## Estrutura de arquivos

- `index.html` - página principal do portfólio
- `style.css` - estilos da página
- `script.js` - scripts para animação de texto, modal de projetos e botão de voltar ao top
- `imagem/` - pasta com imagens usadas no site
- `imagem/anime_Image.png` - ilustração usada na seção principal

## Como usar

1. Clone o repositório:

```bash
git clone <URL-do-repositório>
```

2. Abra o arquivo `index.html` diretamente no navegador.

3. (Opcional) Para melhor visualização, sirva o projeto em um servidor local, por exemplo:

```bash
# com Python 3
cd portfolio-webpage
python3 -m http.server 8000
```

Em seguida, acesse `http://localhost:8000`.
